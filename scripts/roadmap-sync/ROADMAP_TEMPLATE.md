# Project Roadmap Template

<!-- 
ROADMAP FILE FORMAT
This template defines the standard format for roadmap files in this project.
Each roadmap file should follow this structure to ensure compatibility with the sync script.

METADATA FORMAT:
Each task can include metadata in HTML comments that will be used for GitHub Projects integration:
- Priority: low, medium, high, urgent
- Size: xs, s, m, l, xl
- Type: feature, bug, chore, docs
- Assignee: GitHub username
- Due: YYYY-MM-DD

Example:
<!-- priority:high size:m type:feature assignee:username due:2025-05-01 -->
