I spent the night refactoring my Comic Panel App, which got me thinking about the tradeoffs of AI-assisted coding approaches.

Agentic AI tools are incredible for rapid development. You can build more features in days than would take weeks with traditional coding. But there's a catch that becomes increasingly apparent as projects grow...

Technical debt piles up FAST. 

A big goal in my #Agentic workflow is maintaining a clean architecture that both human and AI can understand. Here's what works for me:

#TIPS

👉🏾 My workflow starts with thoughtful planning. I write clear, properly sized tasks with specific acceptance criteria and have AI create a plan of action before diving in.

To optimize token usage, I offload planning work to browser-based tools like #Claude (which can import GitHub repos directly), saving #Windsurf's allocation for actual code changes. This preparation phase is crucial for keeping the project on track.

👉🏾 During development, I use commits strategically to track progress and make reverting changes easier. With Windsurf, I can isolate Cascade changes and apply them only when they're working correctly. 

I address lint errors and warnings immediately before they multiply, and I reorganize code aggressively to reduce technical debt. Pay close attention to the #problems tab, and fix EVERYTHING. Never procrastinate.

👉🏾 Specify in prompts that existing code should be used when possible, since AI's limited context means it might forget what's already been done between sessions.

Consider maintain a change/logging system beyond git that tracks changes and updates. These logs can be referenced in future prompts to help the AI understand the project's evolution and intent. I will often load this information into context so that my agent #remembers what we worked on previously. I update my log file every time I complete a work session, or start a new chat.

🔥 An added benefit of keeping a log is that you can use it to help generate social media content or to help with explain your process and work to stakeholders.

These practices aren't entirely new, but they become even MORE critical when working with AI. Things can quickly get out of hand!
